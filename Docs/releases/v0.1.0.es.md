# Versión 0.1.0

[English](v0.1.0.md) · 25/10/2026.

Primera versión de la implementación alternativa de Portfolio API. El commit integrado en dev con CI aprobada se identifica mediante el tag anotado v0.1.0 y sirve como revisión inicial de main, sin cambiar el contenido entre ambos pasos. package.json ya declara 0.1.0; no se incrementa artificialmente la versión.

## Alcance

Seis contratos HTTP con handlers TypeScript, cuotas compartidas y admisión global de IA, cancelación/deadline, configuración externa validada y fallback versionado. Infraestructura CDK revisable con una función agrupada, HTTP API IAM, tabla de control y secretos externos. La entrega exige PR, verify y merge por workflow con identidad humana; conserva artifacts por revisión/run e inventario de hashes.

La primera instalación AWS será única. Conserva los identificadores test existentes y comienza su validación con proveedores simulados. La variante regional de permisos API Gateway está elegida para la cuenta personal de único operador, con su alcance sobre APIs existentes documentado. No se crea otra stack productiva paralela ni se incorpora emulación local de AWS.

## Validación y límites

580 pruebas: 513 de aplicación, 49 de tooling y 18 de infraestructura. Reproducción local desde archivos públicos, paquete aislado, recuperación del artifact, synth sin lookups, actionlint y cfn-lint aprobados; audit sin vulnerabilidades reportadas. Las policies propuestas se validaron con IAM Access Analyzer sin hallazgos finales. Cada integración y la creación de main vuelven a ejecutar CI.

La versión no acredita despliegue AWS ni validación administrada. Roles/bootstrap/secreto, empaquetado de los dobles, primer changeset, ejecución y ensayo de recuperación siguen pendientes. El tag y la creación de main no disparan el despliegue. Las APIs originales y EC2 siguen operativas; no cambia el tráfico ni se ejecutan envíos, suscripciones o IA real.
