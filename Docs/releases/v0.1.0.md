# Version 0.1.0

[Español](v0.1.0.es.md) · 2026-10-25.

First version of the alternative Portfolio API implementation. The integrated dev commit with successful CI is identified by annotated tag v0.1.0 and serves as main's initial revision, without content changes between those steps. package.json already declares 0.1.0; no artificial version increment is needed.

## Scope

Six HTTP contracts with TypeScript handlers, shared quotas and global AI admission, cancellation/deadline, validated external configuration and versioned fallback. Reviewable CDK infrastructure defines one grouped function, IAM HTTP API, control table and external secrets. Delivery requires PR, verify and human-identity workflow merge, retaining artifacts by revision/run with a hash inventory.

The first AWS installation is the only planned installation. It retains existing test identifiers and starts validation with simulated providers. Regional API Gateway permissions are chosen for the single-operator personal account, with their scope over existing APIs documented. No parallel production stack or local AWS deployment emulation is added.

## Validation and limits

580 tests: 513 application, 49 tooling and 18 infrastructure. Public-source local reproduction, isolated package, artifact recovery, lookup-free synth, actionlint and cfn-lint passed; audit reported no vulnerabilities. Proposed policies passed IAM Access Analyzer without final findings. Each integration and main creation run CI again.

This version establishes neither an AWS deployment nor managed validation. Roles/bootstrap/secret provisioning, doubles packaging, the first changeset, execution and recovery rehearsal remain pending. Tagging and main creation do not trigger deployment. Original APIs and EC2 remain operational; traffic does not change and no real email, subscription or AI effects run.
